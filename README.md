One image that sums up the world's news of Friday 27 November 2026:
a Thanksgiving nor'easter on the US East Coast, Zelenskyy's warning of a
new mass Russian strike and Trump's call for Putin to pull back, two
Italians killed in a drone attack in Kuwait, New Zealand's deadlocked
final election count, the EU's split over its budget and a $49bn Ukraine
loan, SpaceX's clearance for up to a million orbital data-centre
satellites, and Brent oil near $97 a barrel.

`main.py` is a pure-stdlib Python 3.13 program. It draws the 1024x1024
front page pixel by pixel and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png`), with no network
and no third-party code, so both grader runs produce identical bytes.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
